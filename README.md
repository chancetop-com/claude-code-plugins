# Claude Code Plugins Marketplace

This repository is a marketplace for Claude Code plugins maintained by the Chancetop.

## Installation

Add this marketplace to your Claude Code installation:

```shell
/plugin marketplace add chancetop-com/claude-code-plugins
```

## Available Plugins

### core-ng

core-ng development tools and workflows.

**Install:**
```shell
/plugin install core-ng@chancetop
```

## Usage

After adding the marketplace, you can:

1. **Browse available plugins:**
   ```shell
   /plugin
   ```
   Then navigate to the **Discover** tab

2. **Install a plugin:**
   ```shell
   /plugin install plugin-name@chancetop
   ```

3. **Update marketplace listings:**
   ```shell
   /plugin marketplace update chancetop
   ```
